# Fire & Ice Associate Rally — Food & Beverage Trivia

Projector-first open-answer trivia for the Fire & Ice associate rally.

## Live pages
- Main projector presentation: `https://ryangivans.github.io/Trivia/`
- Operator controls: `https://ryangivans.github.io/Trivia/operator.html`
- Printable answer sheet: `https://ryangivans.github.io/Trivia/answer-sheet.html`
- Archived multiple-choice version: `https://ryangivans.github.io/Trivia/multiple-choice.html`

## Game format
- 100 questions in one fixed order
- No multiple choice on the main presentation
- Easy questions = **2 tickets**
- Medium questions = **4 tickets**
- Hard questions = **10 tickets**
- Ticket value is shown on the projector before the answer is revealed
- The answer sheet follows the exact same order as the projector

## Projector controls
- Space / Enter — reveal or hide answer
- Right / Left Arrow — next / previous
- T — start or pause timer
- O — clean projector mode
- F — fullscreen

## Files
- `index.html` — main projector presentation
- `operator.html` — separate operator window
- `questions.js` — fixed ordered question library with ticket values
- `answer-sheet.html` — printable host answer sheet
- `answer-sheet.csv` — spreadsheet-friendly answer sheet
- `multiple-choice.html` — archived original version
- `fire-and-ice-logo.png` — Fire & Ice logo
